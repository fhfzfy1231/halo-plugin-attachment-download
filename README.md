# Halo 附件下载

为 Halo 默认编辑器增加“附件下载”内容块。发布文章时可以直接从 Halo 附件库选择文件，前台以下载按钮显示，适合 Juno / SimpleRockets 2 飞行器 XML、压缩包、配置文件等附件。

## 功能

- 在默认编辑器 `+` 工具箱中增加“附件下载”。
- 支持输入 `/` 后搜索“附件下载”插入。
- 直接调用 Halo 自带附件选择器，不需要重复上传文件。
- 单个下载块选择一个附件，可随时重新选择。
- 自动保存附件名称、大小和固定访问地址。
- 前台显示独立的“下载文件”按钮，并使用浏览器 `download` 行为触发下载，避免 XML 被当作网页直接预览。
- 下载块使用内联样式，不依赖当前主题的 CSS。

## 要求

- Halo >= 2.25.0
- 使用 Halo 默认富文本编辑器

## 使用方法

1. 在 Halo 后台安装并启用本插件。
2. 编辑文章，在工具箱中点击“附件下载”，或者输入 `/` 搜索“附件下载”。
3. 点击“选择附件”，从 Halo 附件库选择需要发布的文件。
4. 发布文章。
5. 访客点击“下载文件”即可保存附件，而不是进入 XML 预览页。
