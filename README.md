# Halo 附件下载

为 Halo 默认编辑器增加“附件下载”内容块。发布文章时可以直接从 Halo 附件库选择文件，前台以受权限保护的下载按钮显示，适合 Juno / SimpleRockets 2 飞行器 XML、压缩包、配置文件等附件。

## 功能

- 在默认编辑器 `+` 工具箱中增加“附件下载”。
- 支持输入 `/` 后搜索“附件下载”插入。
- 直接调用 Halo 自带附件选择器，不需要重复上传文件。
- 单个下载块选择一个附件，可随时重新选择。
- 自动保存附件名称、大小和 Halo 附件标识。
- 提供“下载受保护附件”Halo 角色权限，只有被授予权限的用户才能下载。
- 未登录或没有下载权限时点击按钮，弹窗显示“请登录后下载”。
- 下载经过插件后端权限接口并强制使用 `Content-Disposition: attachment`，避免 XML 被当作网页直接预览。
- 发布后的文章 HTML 不暴露附件原始 URL，避免绕过下载按钮直接获取地址。
- 下载块使用内联样式，不依赖当前主题的 CSS。

## 要求

- Halo >= 2.25.0
- 使用 Halo 默认富文本编辑器

## 更新说明

### v1.1.0

- 新增“下载受保护附件”角色权限，可在 Halo 的角色权限中分配给需要下载的用户。
- 未登录或无权限用户点击下载时弹出“请登录后下载”。
- 下载改由插件后端受保护接口转发，并强制返回附件下载响应。
- 文章 HTML 不再保存附件原始下载 URL，仅保存 Halo 附件标识。
- v1.0.x 已插入的旧下载块需要在编辑器中重新选择一次附件后启用权限保护。

- 保留 v1.0.1 对 NodeView 渲染和附件信息解析的修复

### v1.0.1

- 修复选择附件后下载块在编辑器中显示为空白的问题。

## 使用方法

1. 在 Halo 后台安装并启用本插件。
2. 编辑文章，在工具箱中点击“附件下载”，或者输入 `/` 搜索“附件下载”。
3. 点击“选择附件”，从 Halo 附件库选择需要发布的文件。
4. 发布文章。
5. 在 Halo 中创建或编辑角色，为允许下载的用户授予“附件下载 → 下载受保护附件”权限，并把角色分配给用户。
6. 有权限的用户登录后点击“下载文件”即可保存附件；未登录或无权限时会提示“请登录后下载”。
